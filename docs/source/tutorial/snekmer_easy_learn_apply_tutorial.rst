Learn/Apply Tutorial
====================

``snekmer easy-learn-apply`` is the recommended way to run the Learn/Apply pipeline.
Provide your training sequences, query sequences, and annotation information. Snekmer
handles directory setup, configuration, and the handoff between pipeline stages automatically.

.. list-table::
   :header-rows: 1
   :widths: 50 50

   * - Situation
     - Recommendation
   * - First time running, want results fast
     - ``easy-learn-apply``
   * - Existing ``config.yaml`` and directory layout
     - ``snekmer learn`` then ``snekmer apply``
   * - Adding new training data to an existing model
     - ``snekmer learn`` then ``snekmer apply``
   * - Exploring parameters interactively
     - ``easy-learn-apply`` wizard


What you need
-------------

Three inputs are required:

.. list-table::
   :header-rows: 1
   :widths: 20 15 65

   * - Input
     - Flag
     - Description
   * - Training sequences
     - ``--train``
     - FASTA file **or** directory of FASTA files with known annotations
   * - Query sequences
     - ``--query``
     - FASTA file **or** directory of FASTA files to annotate
   * - Annotations
     - ``--ann``
     - Path to a ``.ann`` file (tab-separated: ``id`` and ``family`` columns)
   * - *(or)*
     - ``--create-ann``
     - Auto-generate annotations from training FASTA headers (see below)

**Annotation file format (.ann)**

A tab-separated file with two columns:

.. code-block:: text

   id              family
   A0A2D0MWR0      TIGR04183
   A0A2D0MY79      TIGR04131
   A0A1Y4R5C6      TIGR00722

The ``id`` must match the accession in your training FASTA headers. For UniProt-style
headers (``>db|ACCESSION|name ...``), Snekmer extracts the field between the first pair
of ``|`` characters. Family labels can be any string: database accessions, descriptive
names, or numbers. Labels are case-sensitive.

**Auto-generating annotations with --create-ann**

If your training FASTA headers encode the family label between pipes, you can skip the
``.ann`` file entirely:

.. code-block:: text

   >db|FAMILY_LABEL|seqid description

Pass ``--create-ann`` and Snekmer will parse the headers and write the annotation file
for you.


Demo data
---------

The demo data is included in the repository under ``resources/demo_sequences/learn_apply_inputs/``:

.. code-block:: text

   resources/demo_sequences/learn_apply_inputs/
   ├── learn/                        ← 10 training FASTA files
   │   ├── training_sequences_1.fasta     (1,000 proteins each; 10,000 total across 200 TIGRFAM families)
   │   ├── ...
   │   └── training_sequences_10.fasta
   ├── apply/                        ← 1 query FASTA
   │   └── test_sequences_1.fasta        (3,000 proteins: in-family, other families, unannotated)
   └── annotations/
       └── TIGRFAMs_annotation.ann   ← id/family TSV

All commands below assume you are running from the **root of the Snekmer repository**.


Running the pipeline
--------------------

Run the full Learn/Apply pipeline with a single command:

.. code-block:: bash

   snekmer easy-learn-apply \
       --train  resources/demo_sequences/learn_apply_inputs/learn \
       --query  resources/demo_sequences/learn_apply_inputs/apply/test_sequences_1.fasta \
       --ann    resources/demo_sequences/learn_apply_inputs/annotations/TIGRFAMs_annotation.ann \
       --output my_results

All parameters (k-mer length, alphabet, etc.) have defaults suitable for most analyses.
No ``config.yaml`` or directory setup is needed.

You should see output similar to:

.. code-block:: text

   --- Running snekmer learn ---
   [Snakemake output ...]

   Copying learn outputs to apply input directories...

   --- Running snekmer apply ---
   [Snakemake output ...]

   === Complete ===
   Results: /path/to/my_results/apply/snekmer_results.csv


Output structure
----------------

After running, the output directory contains two sub-workspaces:

.. code-block:: text

   my_results/
   ├── learn/
   │   ├── input/          ← symlinks to training FASTA files
   │   ├── annotations/    ← your .ann file
   │   ├── config.yaml     ← auto-generated config
   │   ├── apply_inputs/   ← handoff files for apply (generated by learn)
   │   │   ├── counts/kmer_counts_total.csv
   │   │   ├── stats/family_summary_stats.csv
   │   │   └── confidence/global_confidence_scores.csv
   │   └── output/
   │       ├── learn/      ← per-file and total kmer count matrices
   │       └── eval_conf/  ← confidence scores and family stats
   │
   └── apply/
       ├── input/          ← symlinks to query FASTA files
       ├── counts/         ← kmer_counts_total.csv (copied from learn)
       ├── confidence/     ← global_confidence_scores.csv (copied from learn)
       ├── stats/          ← family_summary_stats.csv (copied from learn)
       ├── config.yaml     ← auto-generated config
       ├── snekmer_results.csv  ← main results file
       └── output/
           └── apply/      ← per-file kmer_summary CSVs

The main results file is ``my_results/apply/snekmer_results.csv``.


Reading the results
-------------------

Open ``snekmer_results.csv`` in any spreadsheet tool or with Python/R. Each row is one
query sequence:

.. code-block:: text

   Sequence                          Prediction   Score    delta   Confidence
   tr|A0A2S8EUS7|A0A2S8EUS7_9RHOB   TIGR01783    0.199    0.00    0.383
   tr|A0A401ZGP4|A0A401ZGP4_9CHLR   TIGR00757    0.316    0.02    0.922
   tr|A0A427BXE3|A0A427BXE3_9GAMM   TIGR01023    0.198    0.08    1.000
   tr|J2LWC9|J2LWC9_9BURK           TIGR00797    0.211    0.00    0.383
   ...

.. list-table::
   :header-rows: 1
   :widths: 20 80

   * - Column
     - Description
   * - ``Sequence``
     - Sequence identifier from the FASTA header
   * - ``Prediction``
     - Predicted family (highest cosine similarity to training profiles)
   * - ``Score``
     - Cosine similarity between the sequence and the predicted family
   * - ``delta``
     - Gap between the top and second-best similarity scores
   * - ``Confidence``
     - Calibrated probability that the prediction is correct (0–1)


Filtering by confidence
-----------------------

All sequences receive a prediction. Use **Confidence** and **Score** to filter
for reliable annotations:

- **Confidence ≥ 0.95** is a good starting threshold for high-quality calls.
- **Score = 0.0** means no overlapping k-mers with any training family; exclude
  these predictions.

Using the demo data with a 0.95 confidence threshold, 995 of 3,000 query sequences
receive a high-confidence annotation.

To filter in Python:

.. code-block:: python

   import pandas as pd
   df = pd.read_csv("my_results/apply/snekmer_results.csv")
   high_conf = df[(df["Confidence"] >= 0.95) & (df["Score"] > 0)]
   print(f"{len(high_conf)} high-confidence predictions")
   high_conf.to_csv("high_confidence_results.csv", index=False)


Interactive mode
----------------

Omit any required flag and Snekmer will prompt for it interactively:

.. code-block:: bash

   snekmer easy-learn-apply

.. code-block:: text

   === Snekmer easy-learn-apply ===

   Step 1  Training sequences (file or directory path): /path/to/train/

   Step 2  Query sequences (file or directory path): /path/to/query.fasta
     Found 10 training file(s), 1 query file(s).

   Step 3  How are your training sequences annotated?

     [1] Family labels are embedded in FASTA headers (between | | characters)
         Example:  >db|TIGR04183|seqid Description text
                          ^^^^^^^^
                     this field becomes the family label
         (equivalent to passing --create-ann)

     [2] I have a separate annotation file (.ann)
         Format: tab-separated with columns: id  family
         (equivalent to passing --ann <path>)

     Choice [1]: 2

     Path to annotation file (.ann): /path/to/annotations.ann

   Step 4  Output directory [snekmer_easy_output]: my_results

You can mix flags and wizard: provide ``--train`` and ``--ann`` but omit ``--query``,
and only the query prompt will appear.


Key parameters
--------------

Run ``snekmer easy-learn-apply --help`` for the full option list. The most commonly
adjusted parameters:

.. list-table::
   :header-rows: 1
   :widths: 25 20 55

   * - Flag
     - Default
     - Description
   * - ``--k``
     - ``8``
     - K-mer length
   * - ``--alphabet``
     - ``2`` (solvacc)
     - Amino acid reduction alphabet (0–5 or name; see ``--help`` for full list)
   * - ``--selection``
     - ``top_hit``
     - Annotation selection method: ``top_hit``, ``greatest_distance``, ``combined_distance``
   * - ``--threshold``
     - ``Median``
     - Family score threshold: ``Median``, ``Mean``, ``90th Percentile``, ``None``
   * - ``--apply-output``
     - ``snekmer_results.csv``
     - Output filename for the results CSV
   * - ``--cores``
     - all CPUs
     - Number of CPU cores to use
   * - ``--dry-run``
     - —
     - Show pipeline steps without executing
   * - ``--create-ann``
     - —
     - Generate annotation file from FASTA headers (``>db|FAMILY|seqid``)
   * - ``--copy-files``
     - —
     - Copy input files into the workspace instead of symlinking
   * - ``--fragmentation``
     - off
     - Split training sequences into fixed-length fragments before k-merizing
   * - ``--frag-length``
     - ``50``
     - Fragment length in amino acids (must be ≥ ``--k``)
   * - ``--min-length``
     - ``50``
     - Minimum fragment length to retain; shorter fragments are discarded

For advanced use (adding to an existing model or using custom config files),
use ``snekmer learn`` and ``snekmer apply`` directly. See the
:doc:`full pipeline reference <snekmer_learnapp_tutorial>`.
